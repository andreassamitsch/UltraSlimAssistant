## Audio
pulseaudio.spec line 6: version 15.0; systemd/system/pulseaudio-tv.service.in line 8 runs PulseAudio. Generic ALSA source and echo-cancel modules exist; actual device server configuration unknown.
tzav-media-mt8532.zip includes nested tzav-media-mt8532-mdp_alsa.tgz (199 regular entries). Specific drivers mdp_alsa/mt8532-afe-pcm.c, pcm3.c, pcm4.c and common/mtk-afe-fe-dai.c implement capture stream cases. mt8532-sound3.c includes multiple dpcm_capture=1 entries (502–542); sound4.c includes capture entries (420,433).
mdp_alsa/swdsp/mas_thread/etc/asound.conf line 30 uses Capture_Mic_normal; lines 182 and 187 reference Capture_Voice_Upload and Capture_Echo_Reference. aasound.conf lines 7,20,50,54 define Capture_Mic_ais_only, Capture_Mic_normal, Capture_Voice_Upload, Capture_Echo_Reference respectively. These are platform-specific aliases; exact hardware mapping and availability on S800D not yet established. Prefer normal microphone input and preserve physical mute; do not capture from playback or echo-reference unintentionally.
