## P1: candidate audio interfaces and voice service analysis

- [Samsung Product Microphone API](https://developer.samsung.com/smarttv/develop/api-references/samsung-product-api-references/microphone-api.html) is explicitly scoped to TV/B2B products. It documents public microphone privilege, connected-microphone enumeration, configuration and microphone event notifications. This is not evidence of availability, built-in microphone access or PCM streaming on the S800D. No recording methods tested. If an authorized compatible Web runtime is established, query capabilities and enumerate only before any explicit recording test.
- [Samsung SystemInfo capability keys](https://developer.samsung.com/smarttv/develop/api-references/tizen-web-device-api-references/systeminfo-api/getting-device-capabilities-using-systeminfo-api.html?device=signage) distinguish microphone availability and audio recording; generic getUserMedia support is conditional on device capability and permissions. [VoiceControl API](https://developer.samsung.com/smarttv/develop/api-references/tizen-web-device-api-references/voicecontrol-api.html) is for speech control, not proof of a raw microphone stream.
- [Amazon's generic AVS device architecture](https://developer.amazon.com/en-US/blogs/alexa/post/ba17fd33-6510-45d6-b682-ee9ed9ef589c/single-soc-dev-kits-for-av) separates audio front end, wake-word engine and AVS client. [Soundbar design examples](https://developer.amazon.com/en-US/alexa/devices/speakers/soundbars-avrs-with-mic) discuss commercial device integrations. This is a conceptual model only, not a verified Samsung implementation or a usable custom assistant interface. No Alexa Skill, provider impersonation or traffic interception.
- Re-read actual logs 139558093681, 139561025212 and 139562466757: the selected keyword search found no new matching Alexa/voice-service/focus evidence in the first two logs and six previously known FFP references in the third. Prior scan was not designed for comprehensive voice-service discovery; absence from excerpts is inconclusive.
